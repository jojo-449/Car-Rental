# RUN FRONTEND
cd frontend
npm install
npm run dev


# RUN BACKEND (plain Python, no uv needed)
Requires Python 3.13 or newer.

cd backend

1. to create the .env file
   Windows:      copy .env.example .env
   Linux/macOS:  cp .env.example .env
   Make sure it has PORT=8080 and your frontend address in ALLOWED_ORIGINS.

2. Create and activate a virtual environment (first time only to create)
   python -m venv .venv

   Windows (cmd):         .venv\Scripts\activate.bat
   Windows (PowerShell):  .venv\Scripts\Activate.ps1
   Linux/macOS:           source .venv/bin/activate

   (On Linux/macOS use python3 if python is not found.)

3. Install dependencies (first time only)
   pip install -r requirements.txt

4. Start the server
   python main.py

   This reads HOST and PORT from .env, so it starts on http://localhost:8080.
   API docs: http://localhost:8080/doc

   The database (database.db) is created and seeded automatically on first start.

Alternative start command (the uvicorn CLI ignores .env, so the port must be given):
   uvicorn main:app --reload --port 8080
